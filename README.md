# ScaleQL

Тренажёр аналитика данных: лекции, задачи с автопроверкой и тесты поверх
настоящей базы. Локальное приложение — Python + DuckDB, без внешних сервисов.

![стек](https://img.shields.io/badge/python-3.12-blue) ![база](https://img.shields.io/badge/duckdb-1.x-yellow)

## Что внутри

- **14 юнитов, 41 задача, 25 тестов** — от `SELECT` до оконных функций,
  когорт и retention.
- **Настоящие данные**: год работы вымышленного сервиса по подписке —
  5 200 пользователей, 1 670 подписок, 6 580 платежей, 46 618 событий,
  расходы на рекламу по каналам. В данные заложены реальные аномалии:
  провал биллинга в июне, канал с высокой конверсией в регистрацию и низкой
  в оплату.
- **Автопроверка**: запрос сравнивается с эталоном, расхождение объясняется
  словами — не та группировка, потерян фильтр, сбит порядок строк.
- **Ошибки базы переводятся на русский**: `Binder Error` объясняется вместо
  того, чтобы пугать.
- **Механика удержания**: XP за задачи и тесты, серия дней, дневная цель,
  напоминания в Telegram.

## Две версии

| | где живёт | зачем |
|---|---|---|
| **web/** | Cloudflare Pages, открывается с любого устройства | основная. База DuckDB работает прямо в браузере, прогресс — в localStorage |
| **platform/** | локально, `./start.sh` | версия с сервером на Python: удобнее править уроки и сразу видеть результат |

Интерфейс тоже один: вёрстка, дизайн-система и экраны живут в
`platform/static` и копируются в `web/` при сборке. Отличается только слой
данных — `js/api.js`: на локальной версии это запросы к серверу, в браузерной
подставляется `api.web.js` с DuckDB-WASM и localStorage.

Программа курса одна на обе — `platform/curriculum.py`. После правок:

```bash
.venv/bin/python build_web.py
```

Скрипт пересобирает `web/course.json`, схему и parquet-файлы и прогоняет все
эталонные запросы по базе: если задача стала нерешаемой или возвращает пустоту,
он об этом скажет.

## Запуск локальной версии

```bash
./start.sh
```

Открывается на http://localhost:8777

## Публикация статической версии

Cloudflare Pages, без сборки:

- **Build command** — пусто
- **Build output directory** — `web`

Движок базы (около 6 МБ в сжатом виде) грузится с jsDelivr и дальше живёт
в кэше браузера. Сами данные — 162 КБ parquet, лежат в репозитории.

Через CLI:

```bash
npx wrangler pages deploy web --project-name scaleql
```

Первый запуск, если окружения ещё нет:

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python pandas numpy matplotlib seaborn scipy statsmodels jupyterlab duckdb openpyxl
.venv/bin/python data/gen_saas.py
```

## Напоминания в Telegram

Работают из GitHub Actions — сайту для этого просыпаться не нужно.
Расписание в `.github/workflows/reminder.yml`, ежедневно в 20:00 МСК.
Токен и chat_id лежат в секретах репозитория (`TG_TOKEN`, `TG_CHAT`),
адрес сайта — в переменной `SITE_URL`.

Локальная версия умеет ещё и умные напоминания — только если дневная цель
не закрыта: `platform/install_reminders.sh` ставит проверку раз в час.

## Как добавить урок

Юниты лежат в `platform/curriculum.py`. Блоки: `T()` — текст, `E()` — пример
с кнопкой «Выполнить», `Q()` — задача с эталонным запросом и подсказками,
`V()` — тест с вариантами. Эталон задачи проверяется на реальной базе, поэтому
задача не может оказаться нерешаемой или пустой.
